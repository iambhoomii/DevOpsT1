# Code Lifecycle

## Commit

Developer commits code to a feature or develop branch.

↓

## Pull Request

A Pull Request is created for review.

↓

## Build

GitHub Actions automatically checks the repository.

↓

## Test

Basic validation is performed.

↓

## Merge

After approval, the Pull Request is merged into the main branch.

↓

## Deploy

The application is deployed manually to the target environment.

↓

## Verify

The application is tested after deployment.
