# Team Development Lifecycle

## Workflow

1. Create a new feature branch from `develop`.
2. Implement the required changes.
3. Commit changes using meaningful commit messages.
4. Push the branch to GitHub.
5. Create a Pull Request.
6. GitHub Actions automatically performs build and validation.
7. Review and approve the Pull Request.
8. Merge into `main`.
9. Deploy the application.
10. Monitor the deployment and roll back if required.

## Responsibilities

- Developers write and test code.
- Reviewers approve Pull Requests.
- GitHub Actions performs automated validation.
- The project maintainer manages releases and rollbacks.
