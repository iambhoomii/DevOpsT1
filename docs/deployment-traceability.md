# Deployment Traceability

Every deployment must be linked to a specific Git commit.

## Traceability Process

1. Every change is committed with a meaningful commit message.
2. Every Pull Request references the related commits.
3. The commit history in GitHub identifies exactly which version was deployed.
4. Deployment records should include the commit hash for future reference.

## Benefits

- Easy debugging
- Version tracking
- Audit history
- Faster issue resolution
